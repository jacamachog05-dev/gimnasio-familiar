# Gimnasio Familiar

App web para que cada persona de la familia vea su entrenamiento del día, con videos de cada ejercicio, y anote sus pesos.

- Se abre en el celular en `https://jacamachog05-dev.github.io/gimnasio-familiar/`.
- No necesita cuenta: el avance se guarda en cada celular.
- Todo está en `index.html`.
